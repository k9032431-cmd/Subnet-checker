# subcheck — проверка подсетей на «живые» IP

Ты даёшь скрипту список подсетей, он пингует их и выводит только те, где отвечает хотя бы один IP.

## Установка в Termux

```bash
pkg install -y python git
git clone https://github.com/k9032431-cmd/Subnet-checker
cd Subnet-checker && bash install.sh
```

Чтобы результат сам копировался в буфер обмена: `pkg install termux-api` и приложение **Termux:API**.

## Запуск

```bash
subcheck
```
Вставь сообщение из бота целиком (мусор вроде «1 бл.» и эмодзи скрипт пропускает) и нажми **Enter** на пустой строке.

Другие варианты:
```bash
subcheck -c            # взять список из буфера обмена
subcheck list.txt      # взять список из файла
subcheck -a            # найти все живые IP, а не остановиться на первом
subcheck -r 1000       # отправлять медленнее, если сеть/VPN теряет пакеты
```

Результат выводится на экран, сохраняется в `alive.txt` и копируется в буфер обмена.

## Почему быстро

- Пингует сам через ICMP-сокет, без запуска `ping` на каждый адрес: тысячи пакетов в секунду.
- Подсети проверяются по очереди по одному адресу (.1 → .254 → .2 …). Как только в подсети ответил один IP, её адреса больше не пингуются.
- Подсетям, которые не ответили, даётся второй проход (`-n`).

Если ICMP-сокет недоступен, скрипт сам переключится на системный `ping` (медленнее). Включить его вручную можно флагом `--ping`.
